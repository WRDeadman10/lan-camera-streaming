WebRTC Local IP Setting Guide

Comet
Why this is needed: Chromium browsers on Windows conceal local IP addresses behind temporary mDNS hostnames (.local) by default. Mobile phones on your Wi-Fi cannot resolve these hostnames, causing direct peer-to-peer WebRTC connections to fail. Disabling this flag allows direct, zero-quota LAN streaming.
comet://flags/#enable-webrtc-hide-local-ips-with-mdns

Note: Web browsers block direct links to internal ://flags URLs for security. Copy the URL above and paste it into a new tab.

1
Copy the Flag URL using the button above.
2
Open a new tab in your browser, paste the URL into the address bar, and press Enter.
3
Locate the highlighted setting: Anonymize local IPs exposed by WebRTC.
4
Change the dropdown setting from Default to Disabled.
5
Click the blue Relaunch button that appears at the bottom of the browser.
Click "Test Setting Again" after relaunching to verify local IP exposure.
