Transport Protocols & Quick Guide
Mode A: WebRTC (Direct P2P / ICE)
Standard zero-latency mode. Video travels directly device-to-device. The server & zrok tunnel carry signaling only.
Mode B: Fallback (Tunnel Relay)
Binary JPEG frames routed through server when strict corporate firewalls block direct WebRTC UDP.
