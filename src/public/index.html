LAN Camera Streaming

Self-hosted low-latency camera streaming over local network via WebRTC

Choose Your Role

Stream a camera from a phone or laptop, or watch a stream from another device on the same local network or via public zrok tunnel.

📹 Start Streaming (Sender) 📺 Watch Stream (Viewer)

Supported Media Modes

Mode A: WebRTC (Direct/ICE Media)

Lowest latency. Video travels directly peer-to-peer over LAN or via TURN relay. Server & zrok tunnel carry signaling only.

Mode B: Experimental (Video through zrok Tunnel)

Canvas capture & binary JPEG frames routed deliberately through Windows Node.js server. Tested against zrok free daily quota.

Quick Instructions

  1. Ensure both devices are on the same local Wi-Fi or connected via the secure zrok HTTPS tunnel.
  2. On the camera device, click Start Streaming, choose the Media Mode, enter PIN, and generate or enter Room ID.
  3. Grant browser camera permission when prompted.
  4. On the receiving device, click Watch Stream, select the same Media Mode, enter Room ID and PIN.
  5. Monitor real-time throughput, dropped frames, and connection diagnostics in the status panel.
